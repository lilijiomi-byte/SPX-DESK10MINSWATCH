# 日内报告 K 线图模板 (用户定稿, 不得遗漏)

## 制图核心原则 (2026-10-19 用户亲授)
**让读者看得舒服明了是核心要义，K线不能被压扁。**
- 灰底（盘前/亚洲高低区间）永远保留
- 前高/前低虚线只画有参考价值的：
  - 价格当天碰过该线（最低价 ≤ 前低 + 小容差，或最高价 ≥ 前高 - 小容差）→ 画
  - 该线在K线主体附近（距离日内最低/最高价 ≤ 日内波幅的 50%）→ 画
  - 该线很远且价格没碰过 → 不画线，但图例文字保留
- 图例文字永远保留所有数值（开盘/前高/前低/VWAP/前日高低等）
